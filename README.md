# ERP Cake Factory

ERP-система для кондитерской фабрики. Проект автоматизирует процессы от закупки сырья до производства, заказов и отчетности.

## Возможности

- учет заказов и клиентов;
- контроль наличия и расхода сырья;
- управление поставщиками и закупками;
- планирование производства;
- учет готовой продукции;
- формирование производственных и финансовых отчетов;
- разделение ролей пользователей.

## Стек

- HTML, CSS, JavaScript
- Node.js
- Express
- JSON/SQLite scaffold для локального API

## Структура

```text
Candy/project/   frontend демо
server/          Node/Express API
server/routes/   маршруты для заказов, продуктов, материалов и отчетов
```

## Запуск

```bash
cd server
npm install
npm run init-db
npm start
```

После запуска сервер доступен на:

```text
http://localhost:4000
```
