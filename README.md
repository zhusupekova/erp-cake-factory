# erp-cake-factory
ERP-система для кондитерской фабрики
Кондитерская фабрика выпускает широкий ассортимент изделий: торты, пирожные, конфеты, печенье. Для эффективной работы требуется автоматизация процессов — от закупки сырья до отгрузки готовой продукции.
Цель проекта — разработать информационную систему «Confectionery Factory System», которая обеспечивает управление заказами, планирование производства, учёт сырья, контроль качества и формирование отчётов.
Основные задачи системы:
•	учёт заказов и клиентов;
•	контроль наличия и расхода сырья;
•	планирование и контроль производства;
•	учёт готовой продукции и отгрузок;
•	формирование производственных и финансовых отчётов.
Проект демонстрирует применение методологий IDEF0 и DFD для описания процессов работы фабрики и потоков данных между её подразделениями.
